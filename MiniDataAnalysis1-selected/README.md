# Mini Data Analysis

This repository contains my mini data analysis of a wildfire data set, exploring
whether temperature and relative humidity are related and whether that
relationship differs across fuel types.

## Files

- `MiniDataAnalysis1.qmd` — Quarto source file with all code and written answers
- `MiniDataAnalysis1.md` — rendered output of the analysis
- `data/` — the wildfire data set used in the analysis

## How to Use

Install the required packages (e.g., `install.packages("tidyverse")`), then open
`MiniDataAnalysis1.qmd` and render it to reproduce the full analysis.
